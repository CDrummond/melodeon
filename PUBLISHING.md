# Publishing

## Flathub

https://docs.flathub.org/docs/for-app-authors/updates

1. Clone https://github.com/flathub/io.github.cdrummond.melodeon
2. Create a new branch.
3. Make required changes to the manifest, e.g bump version for new release.
4. Commit and push branch.
5. Create a PR, this will trigger a test build.
6. If the test build succeeds there will be a comment on the PR detailing how to install the test build locally.
7. If tne test build looks good, merge the PR. This will trigger a build and push to flathub.
