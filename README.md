Introduction
------------

Simple QWebEngine wrapper for [Material Skin](https://github.com/CDrummond/lms-material) on [Lyrion Music Server](https://lyrion.org/). This application requires
MaterialSkin to be installed on LMS but does not need to be set as the default
skin.


Features
--------

1. Server auto-discovery
2. MPRIS on Linux
3. Configurable zoom level
4. Inhibit suspend during playback
